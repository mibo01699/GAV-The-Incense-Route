## 📐 Technical Foundation

### Precision Requirements:
- **All monetary values use BigInt**.
- **No floating-point arithmetic** anywhere in the codebase.
- **No `parseFloat`** — use `BigInt()` or `Number.isInteger()`.
- **Micro-units** for small values (1 micro-unit = 0.000001 base unit).
- **Validation** on every input before persistence.

### Example:
```javascript
// ❌ INCORRECT (floating-point error)
const balance = 0.1 + 0.2;  // 0.30000000000000004

// ✅ CORRECT (BigInt)
const balance = 10000000000n + 20000000000n;  // 30000000000n exactly
```
